# Introduction

Singullar is a school platform made in Go and Typescript that provides all the features a real world schoolar ERP should offer
- Classes and meetings.
- User registration (principals, supervisors, teachers, parents and students).
- Exercises with real-time feedback.
- Supervision and Metrics.
- Security & Authorization.
- Notications.
- Ads for events, informations & updates.
- Beautiful Interface.
- more...

Singullar also provides rich technical features and modern programming experience. This project extensively uses the following technologies:
- Docker (Containers, Kubernetes etc).
- Golang (Gin, Cobra, Borm, gRCP, Cors etc).
- Typescript (Eslint, Emotion etc).
- React (Redux, React Hook Form, Material UI etc).
- Vite (Rollup).
- more...
